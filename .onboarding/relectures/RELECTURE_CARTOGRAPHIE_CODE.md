# Relecture — CARTOGRAPHIE_CODE.md

## Verdict global
À corriger — la cartographie est solide sur l'inventaire local et les hotspots, mais elle force encore certains comportements runtime et ajoute un commentaire de compatibilité navigateur non prouvé. Pour une cartographie de code, ces glissements de certitude sont bloquants.

## Problèmes bloquants
- [Bloquant] `.onboarding/CARTOGRAPHIE_CODE.md:193-205` présente dans le flux d'exécution « WordPress détermine le template » puis « Sélectionne index.php (seul disponible) » comme un enchaînement certain, alors que le document lui-même reconnaît ailleurs que cette sélection dépend de la hiérarchie WordPress et que d'autres templates peuvent exister hors dépôt. La cartographie doit rester descriptive du code versionné, pas figer un runtime non prouvé. Preuves consultées : [`.onboarding/CARTOGRAPHIE_CODE.md`](/paperclip/instances/default/projects/be2f6065-a710-4a1d-8bb7-531efdbc6f23/805323cb-4ff1-481e-bc7e-05f597695c48/shift-pilot-wp-theme/.onboarding/CARTOGRAPHIE_CODE.md:91), [`.onboarding/audits/ARCHITECTURE_AUDIT.md`](/paperclip/instances/default/projects/be2f6065-a710-4a1d-8bb7-531efdbc6f23/805323cb-4ff1-481e-bc7e-05f597695c48/shift-pilot-wp-theme/.onboarding/audits/ARCHITECTURE_AUDIT.md:17).
- [Bloquant] `.onboarding/CARTOGRAPHIE_CODE.md:240-242` conclut « pas de syntaxe ES6+ (compatible tous navigateurs) ». L'inventaire prouve seulement l'absence d'outillage npm/Babel dans ce dépôt ; il ne prouve ni une compatibilité navigateur globale, ni un périmètre de navigateurs cibles. C'est une extrapolation gratuite. Preuves consultées : [`.onboarding/audits/TESTING_AUDIT.md`](/paperclip/instances/default/projects/be2f6065-a710-4a1d-8bb7-531efdbc6f23/805323cb-4ff1-481e-bc7e-05f597695c48/shift-pilot-wp-theme/.onboarding/audits/TESTING_AUDIT.md:15), [`functions.php`](/paperclip/instances/default/projects/be2f6065-a710-4a1d-8bb7-531efdbc6f23/805323cb-4ff1-481e-bc7e-05f597695c48/shift-pilot-wp-theme/functions.php:1).

## Recommandations de correction
- Dans le flux d'exécution, remplacer la sélection certaine de `index.php` par une branche explicitement hypothétique, ou borner le schéma à ce qui se passe après l'entrée dans `index.php`.
- Supprimer la conclusion « compatible tous navigateurs » ou la remplacer par un constat strictement local sur l'absence d'outillage de build/transpilation.
