# shift-pilot-wp-theme

Thème WordPress pilote de test SHIFT/Paperclip.

## Périmètre versionné

**Seul le thème est sous git.** Le cœur WordPress, la base de données et les plugins
(Contact Form 7, Yoast SEO, WooCommerce) sont gérés directement sur l'hébergement (FTP),
hors de tout dépôt. Toute intervention au-delà du thème passe par un rapport, pas par une PR.

## Développement

Le thème se dépose dans `wp-content/themes/shift-pilot/`. Pas de suite de tests automatisée.
